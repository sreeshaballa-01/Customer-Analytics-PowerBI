# 📊 Customer Analytics Dashboard – Power BI

## 🔷 Overview
This project focuses on analyzing customer behavior, spending patterns, and campaign effectiveness using Power BI. The dashboard provides interactive insights to support data-driven business decision-making.

---

## 📁 Dataset
- Total Customers: 10,000  
- Total Revenue: ₹14 Million  
- Average Spend per Customer: ₹1.45K  
- Average Income: ₹49.93K  

---

## 🎯 Objectives
- Analyze customer demographics and distribution  
- Evaluate spending behavior across segments  
- Assess marketing campaign performance  
- Understand customer engagement and activity trends  
- Identify high-value customer segments  

---

## 📊 Key Features
- Customer segmentation (Age, Education, Family, Activity)  
- Campaign performance analysis  
- Purchase channel analysis (Web, Store, Catalog)  
- Recency-based customer activity segmentation  
- Deal sensitivity and digital engagement analysis  

---

## 💡 Key Insights
- Customers aged 60+ contribute the highest revenue  
- Graduates are the top spending segment  
- Family-oriented customers generate the majority of sales  
- Campaign 3 has the highest response rate (~52%)  
- Purchase channels are evenly distributed across web, store, and catalog  
- No strong correlation between web visits and spending  

---

## 🛠 Tools Used

- DAX  
- Data Visualization
